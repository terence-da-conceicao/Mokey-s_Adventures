# Mokey's Adventures
## Résumé du jeu et contexte de création
Mokey le singe doit parcourir la carte et trouver des clés tout en évitant les bloukachus qui peuvent lui voler ses clés.
Il finira par trouver le donjon où sont enfermés ses amis et les délivrer.
Il s'agit de mon premier projet collectif et de notre première experience en dehors de JavaScript. Nous nous somems familiarisé avec Lua et
la console Pico 8 en peu de temps pour réaliser ce jeu.

## Installation
- Télécharger Pico 8
- Clone ce repo, placer le fichier .p8 dans le dossier "carts" dans les datas de Pico 8
- Ouvrir Pico 8, tapez "load mokeys_adventures.p8" puis "run"
